# Organization setup

Organization: `soc-guide`  
Repository: `soc-guide/soc-guide`

Recommended organization settings:

- Require two-factor authentication for members
- Keep default repository permission at Read or No permission
- Create `maintainers` and `data-contributors` teams when collaborators join
- Pin the main repository on the organization profile
- Optionally create a public `.github` repository with
  `.github/profile/README.md`

Recommended repository settings:

- Public visibility
- Issues enabled
- Discussions optional
- Pages source set to GitHub Actions
- Squash merge enabled
- Delete branches after merge
- Ruleset protecting `main`
