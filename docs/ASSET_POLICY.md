# Asset policy

SOC Guide is unofficial and is not affiliated with the game publisher.

- Prefer links to existing public asset sources over committing large game
  asset archives.
- Commit only assets that are necessary for site reliability and reasonable
  in size.
- Record the original source where practical.
- Do not represent third-party artwork, icons, names, or screenshots as being
  covered by the project's MIT code license.
- Remove an asset promptly when a valid rights-holder request is received.
